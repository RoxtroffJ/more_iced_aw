# More ICED AW

Originally inspired by [iced_aw]. Adds more widgets (and general functionnality) to [iced] 0.14.

## List of widgets

* **parsed_input**: Similar to a text input, but the contained value is parsed.
  Clearly indicates if the parsing was successful or not.
* **grid**: Similar to an [iced] grid, but with different layout options, as shown in the corresponding example.

## List of helpers

* **Color helpers**: Functions to help mix colors and background together.
* **Element vec**: A vec containing elements. This is just to simplify syntax.

[iced]: https://github.com/iced-rs/iced
[iced_aw]: https://github.com/iced-rs/iced_aw
